# Języki interpretowane — fiszki i quiz

## Uruchomienie
Najprościej otwórz `index.html` dwuklikiem w przeglądarce.

Możesz też uruchomić lokalny serwer:

```bash
cd jezyki_interpretowane_FINAL
python3 -m http.server
```

Potem wejdź na: http://localhost:8000

## Co jest w środku
- fiszki z poprawionymi odpowiedziami,
- kody z pytań 9, 10, 15, 22, 23, 24 i 25,
- podział na działy,
- tryb „Umiem / Nie umiem”,
- powtórka trudnych pytań,
- quiz ABCD z punktacją,
- zapis postępu w przeglądarce.
