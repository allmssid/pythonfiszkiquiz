# Języki interpretowane — aplikacja do nauki

## Uruchomienie lokalnie

```bash
cd jezyki_interpretowane_style
python3 -m http.server
```

Otwórz w przeglądarce: http://localhost:8000

Możesz też wrzucić pliki na GitHub Pages.

## Co jest w środku
- ekran wyboru działów,
- fiszki z pytaniami i odpowiedziami,
- oznaczanie: Umiem / Nie umiem,
- tryb „Tylko trudne”,
- quiz z odpowiedziami A/B/C/D,
- zapamiętywanie postępu w przeglądarce.
